# Reseller Program — Conversa AI

> **Status:** Draft proposal
> **Target:** Agencies, software houses, freelancers with existing SMB clients
> **Model:** You bring the client, we handle everything else

---

## 1. How It Works

```
Reseller                           Conversa                         End Client
   │                                  │                                │
   │── Brings client ──────────────▶  │                                │
   │                                  │── Bills client directly ───▶  │
   │                                  │── Pays commission ────────▶   │
   │◀──────────── (quarterly) ──────  │                                │
```

1. Reseller refers a client to Conversa
2. Client signs up and pays Conversa directly (standard pricing)
3. Conversa handles all: infrastructure, development, maintenance, customer support
4. Reseller gets lifetime commission — paid quarterly

---

## 2. Commission Structure

| Plan | Client Pays | Reseller Gets (Flat) | You Keep |
|------|------------|---------------------|----------|
| **Starter** | $29/mo | **$3/mo** (10%) | $26/mo |
| **Growth** | $99/mo | **$10/mo** (10%) | $89/mo |
| **Pro** | $299/mo | **$45/mo** (15%) | $254/mo |

- **Lifetime recurring** — commission runs as long as the client stays active
- **Payout quarterly** — every 3 months, no minimum threshold
- **No cap** — bring as many clients as you want

---

## 3. What Reseller Does vs What Conversa Does

| Reseller | Conversa |
|----------|----------|
| Refers the client | All development & maintenance |
| Handles initial setup call (optional) | Infrastructure & hosting |
| | LLM & AI costs |
| | Customer support for end clients |
| | Billing & collections |
| | Feature updates & improvements |

---

## 4. Why This Works for Resellers

- **Zero technical work** — no coding, no hosting, no support
- **Lifetime passive income** — paid as long as your client stays
- **No risk** — client pays Conversa directly, you never handle billing
- **Upsell path** — start with Starter, move clients to Growth/Pro over time
- **No lock-in** — no minimum commitment or exclusivity

---

## 5. Requirements

- Has existing SMB clients who need AI customer service
- Able to introduce Conversa as a recommendation
- Willing to use a unique referral link or code for tracking

---

## 6. How to Join

1. Contact us with your agency/project details
2. Receive your unique referral link
3. Start referring clients
4. Track commissions in your reseller dashboard
